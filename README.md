# MobiGo

E-commerce especializado en la venta de accesorios para celulares, ofreciendo productos prácticos, modernos y accesibles.

Proyecto de React para la Corporación Universitaria Minuto de Dios (Uniminuto).

## Integrantes

- Andrés Bautista (PL) - Base del proyecto, navegación e inicio
- Aleja - Catálogo de productos con buscador y filtro por celular
- Juan Ardila - Carrito y formulario de contacto

## Tecnologías

React, Vite, React Router, JavaScript y CSS.

## Cómo correrlo

npm install
npm run dev

Luego abrir http://localhost:5173
